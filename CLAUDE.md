# Nebula -- AI Coding Guide

This file is the entry point for AI coding assistants working in this repository.

## Where to find information

1. **`AGENTS.md`** -- Documentation management, coding conventions, project directory, and CI/CD overview. Start here for any code changes.
2. **`README.md`** -- Repository-level introduction. Per-project setup and commands are in each project's own `README.md`.
3. **`<project>/AGENTS.md`** -- Project-specific architecture, conventions, and design references. Always read before modifying a project.
4. **`<project>/specs/`** -- Detailed feature and proposal documents for each project.
   - `specs/features/` -- Business logic and feature specifications (evergreen, kept up-to-date)
   - `specs/proposals/` -- Point-in-time design proposals and RFCs (may be outdated)

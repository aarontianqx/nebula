# 状态帧序列矩阵

宠物资产的单一事实源：每个状态一张 4×4 宫格图 = 16 帧动画，切片为帧序列循环播放。姿态切换 = 换帧序列；帧动画之上叠加程序化微动画（呼吸/拖拽钟摆/落地 squash & stretch）。

> 历史：Phase 1 曾用单张 4×4 宫格（每状态 1 帧 + 程序化晃动）与 Live2D 待机方案；Phase 2 初版为 9/4 帧混合，后升级 25 帧（5×5 + 超分 + RIFE 插帧）。25 帧版因 AI 生成帧非连续动作反而加剧跳变、且分辨率摊薄，回退为 16 帧方案：帧少但每帧是完整连续动作相位，连贯性由生成质量而非后处理保证。

## 状态定义

全部 15 个状态统一 16 帧，宫格按动作相位顺序生成（行序即播放序，一轮 = 一个完整动作循环）。

| 状态 id | 动画内容 | 触发条件 | 播放 fps |
|---------|----------|----------|----------|
| `idle` | 站立正面：呼吸/眨眼/歪头/摇尾微循环 | 默认 | 6 |
| `walk` | 侧面走路步态循环 | 随机走动 + 窗口位移 | 12 |
| `run` | 侧面奔跑 gallop 循环 | 随机走动（25% 概率，位移更快更远） | 16 |
| `cheer` | 后腿站立→举爪欢呼→小跳→落地收势 | 番茄钟完成 / 饮水确认 | 10 |
| `stretch` | 下犬式伸懒腰 + 打哈欠 + 抖毛全过程 | 待机轮换 | 8 |
| `petted` | 眯眼享受→爱心渐现高潮→回落平静 | 点击 / 拖拽落地 | 8 |
| `sleep` | 蜷缩睡觉：呼吸起伏 + Zzz + 翻身 | 待机轮换 | 4 |
| `rest` | 趴卧休息：慢眨眼 + 下巴搁爪 + 摇尾 | 待机轮换 / 番茄钟休息期 | 5 |
| `drink` | 舔水循环 + 抬头吞咽 + 舔嘴唇 | 喝水提醒触发（常驻至点击确认） | 8 |
| `focus` | 戴眼镜凝视：视线扫读 + 若有所思歪头 | 番茄钟专注中 | 5 |
| `tired` | 疲惫喘气 + 打瞌睡 + 惊醒 | CPU 高负载 / 低电量 | 6 |
| `sulk` | 委屈低头 + 抬眼恳求 + 叹气 | 久未互动 | 5 |
| `greet` | 抬爪挥手打招呼多轮 + 收爪 | 应用启动 | 8 |
| `curious` | 左歪头（问号）→右歪头→抬爪疑惑 | 待机轮换 | 6 |
| `grabbed` | 被拎悬空：钟摆晃动 + 蹬腿挣扎 | 拖拽中 | 8 |

## 资产规格与生成管线

1. **AI 生成**：以真实泰迪照片衍生的皮克斯风 4×4 样板图（`assets-src/template-grid-pixar.png`）为角色一致性基准，每状态生成一张 4×4 宫格（1536×1024，每格 384×256），原生分辨率直接使用、无超分。提示词硬性要求：
   - 纯白底、浅灰格线、无文字数字；
   - **动作连续**：16 格为同一动作按时间顺序的连续相位（行序即播放序），首尾帧衔接成环；
   - **地面线恒定**：所有格子的地面高度一致，落地帧爪底回到同一高度，禁止逐帧下沉/上浮；
   - **主体同位同尺寸**：每格主体水平位置与大小一致、离格线留足余量不触边；
   - 步态类（walk/run）四爪与地面接触相位明确（避免"飘着位移"）；drink 的碗每格同位同尺寸恒在；
   - 走路/奔跑统一朝右（向左由渲染端镜像）。
2. **切片 + 压缩**（`scripts/slice_frames.py`，一条命令完成）：
   - 格子内缩 1.2%（裁掉格线）；
   - 背景去除：白底判定 → 边界连通 = 背景 → 封闭白洞剔除（保留眼睛高光）→ 白底去污染反解前景色 + 软边缘；
   - 去噪：保留最大连通域（本体）+ 不触边的装饰（爱心/Zzz/问号）；细线与低填充率碎片（格线残留）剔除；
   - **锚点对齐**（防错位关键）：逐帧以本体（质心 x，脚底 y）为锚点平移对齐，消除 AI 宫格随机漂移；空中动作（run/cheer/grabbed）只做水平对齐，纵向位移是真实动画相位；
   - 触边告警：前景贴格子边 = 截断风险；petted/grabbed 的顶部触边（手/后颈毛刻意出格）为预期白名单，不告警；
   - 状态级共用裁剪窗口：对齐后各帧 bbox 并集统一裁剪 → 同状态所有帧同尺寸，播放零错位；
   - 体型归一化：以 idle 前景面积为基准输出缩放系数到 `manifest.json`；
   - 末段自动 `pngquant --quality=75-92` 有损量化，240 帧总体积 ~6.2MB（`--no-quant` 跳过）。
3. **目检**（`scripts/preview_frames.py`）：切片产物拼成每状态联络表输出到 `/tmp/comet_preview/`。

## 渲染端防裁切与尺寸

- 画布 200×190（窗口 210×200）；idle 站姿高度占画布 85%（约 160 逻辑 px），其余状态按体型归一化系数缩放。
- **fit 保护**（`PetCanvas`）：任何状态缩放后仍超出画布时整体再缩，确保削头/断尾不可能出现。

## 与状态机的关系

- 常驻状态优先级：饮水提醒 > 番茄钟阶段 > 系统高压 > 待机；临时状态（petted/cheer/greet）播完一轮回落（`hooks/usePetStateMachine.ts` 的 `PetController`）。
- 每状态 fps 与资产表见 `src/pet/assets.ts`；待机轮换池（含权重）见 `src/pet/behavior.ts`；走动/奔跑调度见 `src/hooks/useIdleBehavior.ts`。
- 走动 = walk/run 帧循环 + 窗口水平位移（`src/features/walker.ts`）；到达目标点回落常驻状态。

## 重生成 checklist（单状态返工时）

1. 用样板图 + 该状态旧宫格作参考图，生成 4×4 新宫格（注意上文提示词硬性要求），存 `assets-src/frames/{state}_grid_4x4.png`。
2. 跑 `scripts/slice_frames.py`（含自动压缩），检查告警（触边=截断风险）。
3. 跑 `scripts/preview_frames.py {state}` 逐帧目检：削头/错位/下沉/多余碎片/装饰误删/道具丢失（drink 碗）。
